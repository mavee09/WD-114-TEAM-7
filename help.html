Frequently Asked Questions

Why can't I see assignments? Make sure you joined a valid class code on the Join Class page.
Why can't teacher see my account? You only appear after joining a class code created by that teacher.
Can teachers edit or remove students? Yes, teacher dashboard supports student and class management.
